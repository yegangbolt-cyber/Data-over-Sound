# Acoustic Transfer

GitHub Pages에 그대로 올려 사용하는 오프라인 음향 데이터 전송 PWA입니다.

## 설치
1. ZIP을 풀고 안의 파일을 GitHub 저장소 최상단에 모두 업로드합니다.
2. Settings → Pages → Deploy from a branch → main → /(root) → Save.
3. 생성된 `https://...github.io/...` 주소로 접속합니다.
4. Chrome 메뉴에서 앱 설치/홈 화면에 추가를 선택하면 이후 오프라인 실행이 가능합니다.

## 주요 기능
- 인코더/디코더 한 앱 통합
- 모바일 우선 UI
- 텍스트 직접 입력
- 500KB 이하 확장자 제한 없는 임의 파일
- 파일명, MIME 타입, 원본 크기 보존
- 자동 GZIP 압축 또는 무압축
- 안정 / 표준 / 고속 / 터보 4단계
- DQPSK-OFDM 다중 반송파 프로토콜
- 저주파 2중 시작 신호 + chirp 정밀 동기화
- 프레임별 CRC32 및 전체 CRC32
- 직접 스피커 전송
- WAV 생성
- 마이크 실시간 수신
- WAV/MP3 등 음향 파일 최고속 분석
- 1배속 수신 모의실험
- 누락 프레임 표시
- 같은 전송을 다시 재생하면 정상 프레임을 유지하고 누락 프레임만 보충
- 텍스트 파일 수신 시 미리보기/복사
- 바이너리 파일 원본 다운로드
- PWA 설치 및 오프라인 캐시
- 마지막 속도 설정 기억

## 전송 모드
- 안정: 실제 공기 전송 성공률을 우선
- 표준: 기본 권장
- 고속: 가까운 거리와 양호한 스피커/마이크
- 터보: 고품질 음향 환경 또는 파일 모의실험

## 주의
500KB는 지원 가능한 원본 파일 크기 상한입니다. 실제 공기 전송 시간과 성공률은 파일 압축률, 선택한 모드, 반복 횟수, 스피커/마이크의 주파수 응답, 거리, 반향 및 주변 소음에 따라 달라집니다.

모바일에서 HTML 파일을 `content://`로 직접 열면 마이크 권한이 제한될 수 있으므로 마이크 수신은 GitHub Pages HTTPS 또는 설치된 PWA에서 사용하는 것을 권장합니다.
